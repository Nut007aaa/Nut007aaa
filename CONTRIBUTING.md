# Contributing

First off, thank you for considering contributing to the Premium GitHub Profile Kit! 

## Code of Conduct
By participating in this project, you are expected to uphold our Code of Conduct. Please be respectful and professional in all interactions.

## How Can I Contribute?

### Reporting Bugs
If you find a bug or formatting issue (e.g., an SVG looks weird on mobile, or a GitHub Action fails), please open an issue with:
1. A descriptive title.
2. Steps to reproduce.
3. Expected vs actual behavior.

### Suggesting Enhancements
We are always looking for ways to make the profile look even more premium (Apple, Stripe, Vercel aesthetics). If you have an idea:
1. Open an issue describing your idea.
2. Provide a mockup if possible.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added or changed an SVG, make sure it is optimized.
3. Ensure the README remains responsive.
4. Issue that pull request!

## Styleguide
- **SVGs**: Use `Space Grotesk` or `Inter` fonts. Use gradients (`#38BDF8`, `#8B5CF6`, `#22D3EE`). Maintain the dark background `#050816` and surface `#0B1120`.
- **Markdown**: Use semantic HTML where possible for layouts (e.g., `<div align="center">`).
